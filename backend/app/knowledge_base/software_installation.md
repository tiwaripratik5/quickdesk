# Software Installation Requests

## Overview
This guide covers the process for requesting installation of new software or tools on your company device.

## Standard Software (Pre-Approved)
The following software can be installed directly via the Company Software Center without a ticket:
- Microsoft Office Suite
- Google Chrome / Firefox
- Zoom / Microsoft Teams
- Slack
- Visual Studio Code

## How to Install Pre-Approved Software
1. Open **Company Software Center** from your taskbar or Start menu.
2. Browse or search for the application.
3. Click **Install** and wait for the process to complete.
4. No IT ticket required for pre-approved applications.

## Requesting Non-Standard Software
1. Submit a ticket via the IT helpdesk portal at `https://it.company.com/tickets`.
2. Include the following information:
   - Software name and version
   - Business justification
   - License requirements (free/paid, personal/team)
   - Urgency level
3. IT will evaluate the request for compatibility, security, and licensing.
4. Approval typically takes 3–7 business days.
5. Paid software requires Finance approval before IT can proceed.

## Security Policy
- Employees must not install unauthorized software.
- Any software bypassing this process may be flagged and removed.

For urgent requests, contact IT at it@company.com.
